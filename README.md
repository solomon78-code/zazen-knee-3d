# 坐禅の脚組み 3D模型

結跏趺坐・半跏趺坐で膝を痛める仕組み（股関節の外旋が足りないと、膝の内側の半月板が挟まれ、外側の靭帯が伸ばされる）を、実物の骨の形をもとにした3D模型で確かめられる教育用のページです。

- 公開ページ: https://solomon78-code.github.io/zazen-knee-3d/
- ストレッチ・ガイド: https://solomon78-code.github.io/zazen-knee-3d/guide/
